# An unsent remark is its own thread

Each unsent remark is posted as its own review thread. The same text on the same path and line is that thread, so a retry does not open another. A remark with no line is a thread on that phase's file. The window posts through the review port and does not call the host. One body that joins every remark was rejected: the thread's latest marker would answer lines that are not that remark. A review that requests changes was rejected: the flag is not a thread, and the machine classifies threads.
