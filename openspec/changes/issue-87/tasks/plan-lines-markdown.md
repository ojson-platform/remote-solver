## Source

Add the shared renderer in `src/window/client/source-line.tsx`. It takes the `text` of the spine lines `PlanLines` was given, joined by newlines, and parses it with remark. Each painted node keeps remark `position.start` and `position.end` and the node's `value`. The renderer returns the node with that position and that value. Inline emphasis, a link, and code stay inside the block that contains them and keep their own positions. On an indented code block that spans several source lines, the raw indented first line is not in the node value; the first covered line shows the node's value and does not show the raw indented source, and each later covered line shows that line's slice of the value and does not show the previous line slice. A link reference definition covers three source lines; when the definition url and title do not contain the raw source of those lines, each of those lines does not show the raw source. On a closed four-backtick fence, the later covered line whose text is three backticks shows that line slice of the value and is not painted empty. On an indented code block whose value is fence-shaped text, the first covered line shows the node value and is not painted empty, and the next line shows that line slice of the value and does not show the previous line slice of the value. A reference link whose label spans two source lines renders as a link; each of those covered lines shows the node value so the label is visible, and neither line is painted empty. On a closed tilde fence spanning several source lines whose covered lines are alpha and beta, the line alpha shows that line slice of the value and does not show beta; the closing ~~~ marker is not in the node value, so the closing ~~~ line does not show the raw marker. On an unclosed fence whose opening line is the raw marker `` ```fence ``, that marker is not in the node value, and the node value is a blank line followed by x, that opening line does not show the raw source. On a fenced block set in a blockquote, the later covered line shows that line's slice of the value and does not show the raw source. A line the value does not contain does not show the raw source. A run of blank lines that no node covers stays one `span.gap`. A blank line the value contains stays that slice and is not one `span.gap`. The renderer does not read the spine, the draft, the pull request, or the review, and it does not set the data attributes.
