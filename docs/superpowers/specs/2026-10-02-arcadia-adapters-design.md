# Адаптеры Трекера, Арканума и arc

Адаптеры живут в `ai/artifacts/skills/teams/lavka/sdd/sdd-flow/scripts/adapters/`. Публичный репозиторий их не содержит. Поведение портов — спека `docs/superpowers/specs/2026-10-01-tracker-arcanum-cycle-design.md`: ключ тикета, ветка `sdd/<ключ>`, ревью по полю `issues`, таблица статусов AI SDLC, `merge()` возвращается только из уже слитого ревью и не пишет `auto_merge` / `on_satisfied_requirements`.

Ветка `tracker-arcanum-cycle` — источник кода. В публичный `master` она не сливается.

## Модуль

`index.mjs` экспортирует `createAdapters(root, config)` по контракту из спеки пакетирования. Модуль импортирует только `node:*`.

Возвращает `tracker`, `review` и `vcs`. `config` не возвращает. Очереди, база и префикс приходят из аргумента `config`.

Runtime модуль не реализует. Шпион строит `agentRuntime` пакета поверх `vcs` этого модуля, и агент запускается в каталоге, который возвращает `vcs.prepare`.

## Что в переносе исправляется

Собранные на ветке команды не совпадают с `arc` и с каталогом checkout.

- Вершина ветки читается `arc log -n 1 --format={commit} arcadia/<ветка>`. `%H` не используется: `arc` печатает его как текст.
- Предок проверяется так: `arc merge-base <коммит> <вершина>` печатает `<коммит>`. Флага `--is-ancestor` нет.
- `compare` при отсутствующем коммите возвращает `null`. Диапазон запрашивается аргументами, которые `arc diff` принимает. Форма `base...head` не используется.
- `prepare(key, {worktreesDir, links})` создаёт checkout через `arc-wt`, ставит ссылки из `links` в `.sandcastle/` этого каталога без `git`, запоминает путь и возвращает его. Повторный вызов `arc-wt` не запускает. `tip(key)` — вершина локальной ветки в этом каталоге. `filesAt` читает этот каталог, а не `<root>/.sandcastle/worktrees/`.
- `dirty()` не считает `.sandcastle/` изменением.
- `review()` читает обязательные проверки и сворачивает их как в спеке цикла: нет обязательных — `none`, есть красная — `red`, есть ещё идущая — `pending`, все зелёные — `green`. Непрочитанные проверки — исключение, не `green`.

## Checkout и адаптеры в нём

Ссылки `links` ведут в npm-пакет шпиона: оттуда агент читает `.sandcastle/skills/sdd-flow/steps/<шаг>.md` и `CONTEXT.md`. `node scripts/sdd.mjs` из этой копии адаптеры рядом с собой не находит и идёт вверх от cwd до `ai/artifacts/...`. Поэтому checkout, который делает `prepare`, должен содержать `ai/artifacts/skills/teams/lavka/sdd`: фильтр путей `arc-wt`, если он используется, обязан включать этот каталог.

Теги `sdd:auto-*` и `sdd:wait-human` адаптер не интерпретирует. Ошибка адаптера — исключение.

## Проверка

Тесты адаптеров запускаются `node --test` из каталога адаптеров, файлы `*.test.mjs`. Vitest и `npm install` для них не нужны. Сеть в тестах не вызывается: HTTP закрыт подставным `fetch`, `arc` и `arc-wt` — подставным запуском команд.
