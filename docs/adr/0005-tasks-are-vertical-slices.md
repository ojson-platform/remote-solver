# Tasks are vertical slices of existing scenarios

`sdd-tasks` groups scenarios that are already in the delta into caller-visible slices. A later slice may assume an earlier one holds. Each scenario sits in exactly one slice, and the task card names the files. The skill does not invent a scenario.

An external ticket skill was rejected: it questions the person and publishes somewhere else. The stock OpenSpec task list was rejected: it is numbered groups, and the implement skill walks one card, one commit.
