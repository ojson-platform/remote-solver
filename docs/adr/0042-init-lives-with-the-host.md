# Init lives with the host

`sdd-init` connects a service: CI, the trace format, and where the chat command is. Those facts are the host's. The published package ships `sdd-flow` only. A host that connects services keeps the init skill next to its adapters. ADR 0026 recorded the skill as a chat in this package; that part is superseded. The skill is still not a cycle phase and the machine still does not call it.
