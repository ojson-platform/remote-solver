# Host issue links are the child and the blocker

The tracker port is the only seam for parent, blocks, blocked-by, and depends-on. GitHub and Arcanum fill the same fields from the host's own issue links. The settlement waits on a child and a blocker from those fields. The window derives chips from the cards on the board. A `Parent:` line or a `Depends:` line is not a link, and the tasks step writes the host link through an sdd verb.

Reading the body when a host field is empty was rejected: a fallback would keep the body line as a link. Keeping the names in the reason block was rejected: the chip is the mark, and the reason block keeps open questions, Ask, and the merge.
