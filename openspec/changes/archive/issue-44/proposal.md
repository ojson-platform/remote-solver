## Problem

The hammer means a worker is busy on this cycle, so that phase is not waiting for a person.

Today the hammer sits on the Tasks row of an implementing cycle, on the first open task, and the plaque stays bare (#29). That misses a worker on specifying, accepting, or any phase other than implementing.

## Outcome

Hang the hammer on the plaque of the phase the worker is in. A worker improving a spec hangs it on the specifying plaque. A worker archiving hangs it on the accepting plaque. Any phase the running set is actually working gets the same mark. When the worker leaves, the hammer goes. A cycle that is waiting for a person shows no hammer.

The plaque is the mark. The Tasks-row hammer does not stay beside it.
