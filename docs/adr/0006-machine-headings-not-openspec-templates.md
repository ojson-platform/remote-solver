# Proposal and design keep the machine's headings

The machine counts unchecked `## Open questions` and `## Open decisions`, and it will not advance while any remain. It reads the English headings only; the Russian aliases went when no active change used them. Those headings stay, so the proposal and the design do not follow the OpenSpec templates (Why / What Changes, Context / Goals / Decisions). The spec delta does follow `openspec instructions specs`.

The OpenSpec proposal template was tried and removed: it dropped the headings the machine reads.
