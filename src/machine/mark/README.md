# Mark

Read and write what a person and the machine leave on the issue and the pull request.

Every reader of a reply goes through the one marker grammar. A layer on a thread can send the change back. A layer on the conversation is recorded and does not. The mirror is the marked block in the issue body; text outside it stays the author's. Focus prose is checked here. The window shows it unchanged.

Behavior is in `openspec/specs/`.
